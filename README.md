# 🚀 Site Pessoal / Portfólio — CP3

Projeto desenvolvido para o **Checkpoint 3 (CP3)** do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

O projeto consiste em um site pessoal/portfólio desenvolvido com **HTML5, CSS3 e JavaScript**, contendo diferentes páginas para apresentação pessoal, currículo, contato, multimídia e gráficos.

---

---

## 📌 Sobre o Projeto

O site foi desenvolvido como parte da evolução do projeto do **CP2 para o CP3**, tendo como objetivo criar um site pessoal com diferentes conteúdos e páginas interligadas.

O projeto conta com:

* Página inicial;
* Currículo acadêmico e profissional;
* Formulário;
* Página de contato;
* Conteúdo multimídia;
* Página de gráficos;
* Navegação entre as páginas;
* Estilização utilizando CSS;
* Elementos multimídia, incluindo imagem e vídeo;
* Estrutura organizada em arquivos HTML e CSS.

---

# 📄 Páginas do Site

## 🏠 `index.html` — Página Inicial

É a página principal do site.

Nela é apresentada a introdução do portfólio e as principais informações de apresentação do autor.

A página também funciona como ponto de entrada para a navegação pelas demais áreas do site.

---

## 📚 `curriculo.html` — Currículo

Página destinada à apresentação das informações acadêmicas e profissionais.

Nela são apresentadas informações relacionadas à formação e ao perfil profissional do autor.

O objetivo é funcionar como uma versão digital do currículo dentro do portfólio.

---

## 📝 `formulario.html` — Formulário

Página destinada ao formulário de interação com o usuário.

O formulário permite o preenchimento de informações e utiliza os recursos de HTML para organização dos campos.

A página também faz parte da estrutura de navegação do site e pode ser utilizada como uma área de interação com o visitante.

---

## 📞 `contato.html` — Contato

Página destinada às informações de contato.

Ela complementa o formulário e disponibiliza uma área específica para comunicação com o autor do portfólio.

---

## 🎬 `multimidia.html` — Multimídia

Página dedicada à utilização de recursos multimídia.

O projeto possui arquivos de mídia na pasta `img/`, incluindo:

* 🐶 `cachorrogif.gif`
* 🎥 `videoteste.mp4`

Esses recursos são utilizados para demonstrar a utilização de diferentes elementos multimídia em HTML.

---

## 📊 `graficos.html` — Gráficos

Página dedicada à apresentação de informações por meio de gráficos e representações visuais de dados.

Ela complementa as demais páginas do portfólio, demonstrando a utilização de elementos voltados à apresentação visual de informações.

# 🎨 CSS

A estilização do site está centralizada no arquivo:

```text
CSS/estilos.css
```

O arquivo contém as regras responsáveis pela aparência das páginas, incluindo elementos como:

* Layout;
* Tipografia;
* Espaçamentos;
* Cores;
* Formatação de menus;
* Formulários;
* Elementos das páginas;
* Organização visual do site.

A utilização de uma folha de estilos centralizada facilita a manutenção e mantém uma identidade visual consistente entre as páginas.

# 🔗 Navegação

As páginas do projeto são interligadas por meio de links internos.

A estrutura de navegação permite acessar as diferentes áreas do site:

```text
Página Inicial
    │
    ├── Currículo
    ├── Formulário
    ├── Contato
    ├── Multimídia
    └── Gráficos
```

Dessa forma, o visitante consegue navegar entre as diferentes páginas sem precisar acessar os arquivos diretamente.
